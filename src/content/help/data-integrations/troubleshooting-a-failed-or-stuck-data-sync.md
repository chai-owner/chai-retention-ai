description: "Steps to diagnose and fix a data source that isn't syncing as expected in ChAi."
order: 4
---

If a data source isn't syncing as expected:

1. **Check your Integrations settings** to confirm the connection is still authorized — integrations can occasionally need re-authorization if a password or permission changes on the source platform's side.
2. **Re-connect the integration** if it shows as disconnected or errored.
3. **Check for a sync timestamp** to see when the last successful sync happened.
4. If the issue persists, reach out to support@askchai.tech with the integration name and roughly when you first noticed the issue.
