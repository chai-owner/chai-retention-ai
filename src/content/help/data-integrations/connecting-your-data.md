ChAi works from the data you already have. You can connect tools directly, upload files, or do both.

## Supported integrations

- **Accounting:** Xero, QuickBooks, FreshBooks
- **CRM:** HubSpot, Salesforce, Zoho
- **Support:** Zendesk, Intercom, Freshdesk

## Connecting a tool

1. Go to **Data** in the left navigation.
2. Find the tool you want and select **Connect**.
3. Sign in to that tool and approve access.
4. The first sync starts straight away; later syncs run nightly.

## Uploading a spreadsheet

Use **Data Drop** on the Data page. Drop in a CSV or Excel file and ChAi maps the columns for you. You can correct any mapping before saving, and edit rows inline afterwards.

## If the same customer appears twice

Different tools spell names differently. ChAi matches them for you and shows possible duplicates on the **Identity** page, where you can confirm or split them.
