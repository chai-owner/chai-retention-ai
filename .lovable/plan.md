# Principle: AI only where it's truly necessary

## The rule
- **Business logic (default):** anything deterministically derivable from data the scoring engine already produces — health scores, risk categories, churn %, weighted factors, recommendations, counts, totals, sorting. These should be computed in code (e.g. `mock-data.ts`), not generated by a model. They're instant, free, consistent, and SSR/offline-safe.
- **AI (the exception):** open-ended language and reasoning that can't be templated — e.g. the conversational **Ask ChAi** assistant, where the user asks free-form questions.

## Applying it to the current app
- **Ask ChAi** → genuinely AI-necessary. Keep.
- **Dashboard "Needs attention now" summaries** → AI, but **regenerate at most once every 24 hours** (per your decision). Rather than calling the model on every dashboard load, cache the generated summaries and only refresh when the cached set is older than 24h (or when the underlying at-risk accounts change).
- **`assessCustomerRisk`** → dead code (no UI references). Candidate for removal during cleanup.
